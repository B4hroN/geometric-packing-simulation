# Geometric Packing Simulation

Симуляция силовой упаковки фигур с детекцией коллизий и оптимизацией масштаба. Прототип демонстрирует работу геометрических алгоритмов и физического моделирования в браузере.

## Алгоритмы и возможности

- **Separating Axis Theorem (SAT):** Детекция коллизий для произвольных выпуклых многоугольников (проекции, нормали, penetration depth).
- **Force-Directed Layout:** Симуляция сил отталкивания и притяжения к центру для поиска стабильной конфигурации.
- **Оптимизация масштаба:** Бинарный поиск максимального масштаба фигур без пересечений.
- **Жёсткие группы (Rigid Bodies):** Система лидер-ведомый с относительными смещениями и углами. Агрегация сил и моментов для группы.
- **Геометрия:** Работа с вершинами, нормалями, проекциями, моментами сил. Поддержка кругов, прямоугольников, многоугольников и трапеций.

## Стек

## Использование

1. Откройте `index.html` в браузере.
2. Доступные элементы управления:
   - **Один шаг симуляции:** Выполняет итерацию физического шага.
   - **Случайные центры:** Сбрасывает позиции фигур.
   - **Найти максимальный размер:** Запускает бинарный поиск оптимального масштаба.
   - **Слайдеры:** Регулировка масштаба, зазора и количества фигур.

## Роль автора

- **Алгоритмическое ядро:** Разработка логики SAT, force-directed алгоритма, системы групп и бинарного поиска.
- **Архитектура:** Проектирование структуры данных, модулей симуляции и управления состоянием.
- **Реализация:** Использование AI-assisted workflow для ускорения написания кода по заданному алгоритму и архитектуре.
